# Smart Library Management & Book Tracking System

## 📌 Description

Smart Library Management & Book Tracking System is a MySQL-based project developed to manage books, authors, categories, members, borrowing, returns, reservations, and fines. It uses SQL queries, joins, views, stored procedures, functions, and triggers to automate library operations, track book availability, and maintain accurate records.


## 🛠️ Technologies

* MySQL
* SQL
* Views
* Stored Procedures
* Functions
* Triggers
* Joins & Subqueries

## ✨ Features

* Book and member management
* Borrow and return books
* Book reservations
* Fine calculation
* Availability tracking
* Borrowing history
* Overdue book tracking

## 👥 Team Roles

**Member 1 – Database & Book Management**
Database design, tables, relationships, books, authors, and categories.

**Member 2 – Borrowing & Transaction Management**
Borrowing, returns, reservations, procedures, functions, triggers, and fines.

**Member 3 – Reports, Analytics & Testing**
Views, reports, analytics, testing, debugging, and documentation.
